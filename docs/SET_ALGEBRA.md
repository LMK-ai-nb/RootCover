# 0.4 正公式约束与搜索控制

0.4引入、0.5沿用的源码功能；实际发布状态见RELEASE.md。默认无formula时仍要求全部约束成立；本轮不改旧数据的含义。

## 正公式

约束数组是原子谓词目录。每个原子表示“表达式在该点有定义，且值属于指定闭带”。公式用从0开始的原子下标：

```json
"formula": {"all": [4, {"at_least": {"count": 3, "of": [0, 1, 2, 3]}}]}
```

含义：原子4必选，前四个至少三个成立。`all`为全部、`any`为任一、`at_least`为至少k个子谓词。可以嵌套；显式未引用的原子不会偷偷变成必选规则。公式512节点、深度16上限，整体JSON仍受24层嵌套限制（可能更严格）。

不提供NOT/隐式补集、严格不等式或任意布尔代码。AtLeast禁止结构相同的直接子谓词重复计票，但不证明不同公式的逻辑/统计独立性。count不是置信度，也不是故障概率。

## 定义域与证据

每个盒对原子给出true/false/unknown：只有整个盒有定义且区间像在允许带内才为true；像不交或处处未定义为false；其他unknown。

公式的阈值按“已确认true数量”和“仍可能true数量”判定。unknown不投成已成立。复合公式只要求使它成立的分支有效，例如负数范围分支成立时，另一未启用的log分支处处未定义不会推翻集合并。默认全约束逻辑仍拒绝该盒；不会把无效log点冒称log可行。

逻辑内盒保存每个原子的区间像/定义状态/真值及整个公式真值；它不声称所有原子都成立。部分原子range=null表示处处未定义；range=[null,b]或[a,null]表示像端点无界，含义不同。

## 保守组合收缩

- 原子使用现有前后向/区间Newton；纯原子AND可复用联合收缩，非方结构继续支持。
- 组合AND依次收缩，OR对分支独立收缩后取并的盒凸包。
- AtLeast保留所有候选分支，逐坐标计算至少k个候选区间覆盖的区域，再取凸包。若任一轴没有k重覆盖，才可判空。分支预算耗尽会保留原输入盒，不删除未经处理的方案。

坐标q重覆盖只是必要条件，跨坐标可能由不同分支贡献；凸包也可能含不可行空隙。**非空收缩盒不证明可行，必须再做公式区间真值判定和细分。** 不实现完整的双向separator/外域分解。

可行内盒∪未决仍包围原域全部可行点；整盒可行只依赖独立区间真值，不依赖收缩器说“非空”。全查询共享收缩/搜索预算。核心和测试独立编写；概念参考和许可见LANDSCAPE_2026-11-13.md，没有复制/链接上游核心实现。

## 搜索策略与精度

```json
"search": {
  "strategy": "bfs",
  "split": "scaled",
  "absolute_tolerances": [0.05, 0.000005],
  "relative_tolerance": 0.000001
}
```

strategy为dfs/bfs；split为widest/scaled/smear。smear为本库的Jacobian相对影响启发式，不是完整IBEX实现；跳过部分定义/不光滑/非有限导数行，没有有效影响信息时退回归一化宽度。逻辑问题仅使用公式引用的原子作为启发式输入。

逐变量允许宽度为 `max(atol[i], rtol*minimum_abs(box[i]))`，相对项向下舍入；盒跨0时相对项为0，防止远端数量级掩盖零附近细节。rtol∈[0,1]，atol必须为每变量一个正有限值。省略逐变量精度使用原tolerance；默认dfs/widest/rtol0保留旧行为。

relative_scale和实际精度会导出。达到精度不证明存在根/可行点。预算没处理的盒标pending，已经处理仍无法判定的盒标unknown；两者都属于unresolved。单次结果的标签不是检查点；0.5可行域另有保存可复核轨迹的会话接口，见SESSIONS.md；求根仍没有恢复接口。

## 场景

### 1. 含异常观测的区域定位

- 使用者：编写测量融合程序的开发者。问题：四条带误差测距中一条可能异常，要求至少三条观测成立，同时必选边界不可放松。
- 输入：`examples/robust_localization.json`；x/y均在[0,2]，四条平方距离观测，其中第四条人为设置为不一致的[24,25]，另有x+y∈[1.5,2.5]。
- 操作：`node bin/rootcover.mjs examples/robust_localization.json`；公式all包含必选原子4及前四个观测的at_least3。
- 实际输出：15内盒、38未决，resolution_met=true，保留(1,1)；退出1表示仍有未决。逐原子证据能显示异常观测不成立，而整个公式仍可成立。
- 验证：CLI对照删除formula后严格AND可证明空；独立100位参考检查内盒端点/中心，Fraction随机公式检查收缩不丢可行点。不是以某一内盒宣称找出了真实故障传感器。

### 2. 两种非线性设计方案

- 使用者：保留多种备选方案的设计程序开发者。问题：不能把两个互斥设计误写成同时成立，也不能忽略共享资源限制。
- 输入：`examples/design_alternatives.json`；x/y均在[0,3]。方案A为x∈[0.2,1.2]且y接近exp(x/2)；方案B为x∈[1.8,2.8]且y接近sqrt(x)。公共条件为x²+y²≤12。
- 操作：`node bin/rootcover.mjs examples/design_alternatives.json`；使用all(公共条件,any(all(A),all(B)))与BFS/Jacobian影响划分。
- 实际输出：184内盒、204未决，resolution_met=true；保留(0.5,exp(0.25))和(2,sqrt(2))。取凸包产生的中间空隙不被当作内盒。
- 验证：CLI检查两个方案与x=1.5间隙；独立高精度参考检查内盒整公式。保留方案不等于寻找全局最优设计，当前没有优化目标。

### 3. 混合量纲参数估计

- 使用者：编写标定/参数反演程序的开发者。问题：百万量级offset和千分之一量级gain不能共用一个不合适的绝对宽度。
- 输入：`examples/scaled_parameters.json`；offset∈[1000000,1000200]、gain∈[0,0.002]；正弦混合响应与指数响应两条观测带，绝对精度分别0.05与0.000005，相对精度0.000001。
- 操作：`node bin/rootcover.mjs examples/scaled_parameters.json`；BFS/scaled控制细分与停止，实际配置随结果导出。
- 实际输出：226内盒、277未决，resolution_met=true；保留(1000100,0.0005)。未决盒达到宽度仍不当作可行点。
- 验证：CLI逐盒检查有效精度与已知参数保留；独立100位参考检查内盒端点/中心；MoonBit另检查跨零时相对精度不掩盖小尺度。

均为合成模型，数量对应固定版本/配置，不代表真实设备、安全认证或统计可靠性。
