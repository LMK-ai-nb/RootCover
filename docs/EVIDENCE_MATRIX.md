# 证据矩阵

一页看清每项能力"被什么证据支撑"。分为：**跨实现对照**（与 IntervalRootFinding.jl 实际运行结果比对）、**独立参考**（mpmath 100 位 / Fraction 精确算术）、**仅自测**（本仓库测试与已知点核对）、**端到端**（真实浏览器）。

| 能力 | 证据类型 | 范围 | 强度 |
| --- | --- | --- | --- |
| 区域根分类与包围 | 跨实现对照 | 20 模型 × Newton/Krawczyk 两种方法，40 次运行 | 有外部对照；判据为根数相等 + 每个 Julia 细胞被唯一一个本库包围包含 |
| 初等函数值与导数 | 独立参考 | 13 种函数，100 位 mpmath | 有独立参考 |
| 区间四则与向外舍入 | 独立参考 | 2800 组算术、182 系统、513 份根证据 | 有独立参考 |
| 区间 Newton / 收缩 | 独立参考 + 自测 | 134 模型 × 3 种机制共 402 次收缩保留 | 部分：无跨实现对照 |
| 前后向约束传播 | 仅自测 | 正公式 54 模型、284 份精确内盒证据 | 仅自测；概念参考 IBEX，未移植、未对照 |
| 非方约束与组合语义（all/any/at_least） | 仅自测 | 54 模型 + 6 个可行域场景 | 仅自测 |
| SIVIA 内外包围 | 仅自测 + 已知点 | 6 个场景，含 750 内盒 / 1798 未决的组合算例 | 仅自测 |
| 可行域会话（保存/核验/恢复） | 仅自测 | 48 模型、548 份状态、9074 次内盒核对 | 仅自测 |
| 浏览器与 CLI 同核 | 端到端 | 12 个场景，真实 Chromium + 下载报告比对 | 端到端 |

**结论**：9 项里 3 项有跨实现或独立参考，5 项仅自测，1 项为端到端。因此本仓库只声称"求根层与 IntervalRootFinding 0.7.2 做过实际对照"，**不声称传播、组合、SIVIA、会话层与 IBEX/Codac 等价**；这些层的边界见 [PARITY](PARITY.md) B 表与 [STANDARDS](STANDARDS.md)。

复现入口：

```text
python scripts/verify.py                 # 区间/根/可行域/函数 oracles
python scripts/compare_intervalrootfinding.py   # 20 模型跨实现对照
node --test tests/cli.test.mjs           # CLI 与确定性
python scripts/envelope.py               # 可行域体积与未决原因统计
```
