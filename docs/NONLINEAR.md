# 0.3 本地非线性内核

数值内核记录始于0.3.0-dev.1（2026-11-11）；0.4新增正公式和搜索策略，0.5新增可行域会话，见SET_ALGEBRA.md及SESSIONS.md。本章记录源码算法；当前源码/网页/包状态见RELEASE.md。

## 初等函数与舍入

按IEEE-754 binary64、逐次向外舍入解释，要求保留次正规数。没有用宿主sin/exp/log加一个ULP来冒充可靠包围。

- exp：按2的幂缩减到|r|≤1/2，20阶区间Taylor，余项界±1e-24，再平方恢复。exp(|r|)<2，尾项<2*(1/2)^21/21!。极大/极小参数使用保守无界/近零包围。
- log：精确二进制缩放 `x=2^k*m`、m∈[1,2)，使用 `2*atanh((m-1)/(m+1))` 的49阶奇次级数和±1e-23尾界，叠加ln2闭包围。
- sin/cos：以闭π包围缩减象限；|r|≤1时24/25阶Taylor及±1e-25尾界。合并端点与所有可能内部极值。|参数|>1e6或过宽时返回[-1,1]。
- sqrt：浮点位模式二分，用向外舍入的x/c与c比较，避免平方溢出/下溢；c与x/c的凸包包含sqrt(x)。
- atan：倒数/π/4恒等式缩减，81阶交错级数与尾界。asin用有界单调区间二分，acos由π/2−asin构成；tan/双曲函数由已包围的函数和四则构成。
- abs和偶次幂逆传播保留正负分支，不假装全域单调。

π、ln2、余项界和IEEE运算假设属于可审计基础；本实现不是IEEE-1788全标准实现或形式化证明。

## 定义域与导数

`DomainRange.range=None`表示整个盒上表达式处处未定义。否则给出定义点的保守像；fully_defined/smooth表示已证明整个盒有定义/满足连续可微条件，是保守状态。

log跨0、sqrt跨负域、asin/acos跨[-1,1]、除数含0和tan潜在极点不会直接认证整盒可行。abs跨0、sqrt在0和反三角端点不直接获取唯一性证明。复合表达式保留内部定义域，例如log(x)^0不扩展到x≤0。

区间前向AD实现链式/乘积/商规则。只有整个证明域已确认有定义且光滑，才用Jacobian作Krawczyk/Newton证明性收缩；否则采用范围排除、域传播与细分。

## 前向—反向传播

从目标带开始，自然区间像与目标相交，再沿AST反向投影。乘法关系除法在目标和因子均含0时不强行除去0；周期逆像枚举所有可能分支再取凸包，过宽/过大时跳过该项逆剪枝。凸包不表示分支间所有点可行，仍需细分。

约束记录变量依赖，变化重新激活相关约束。每轮传播有调用额度，给Newton保留机会，避免循环agenda把联合机制饿成单一机制。

## 区间Newton与联合机制

对方形子系统，取中心c、区间Jacobian J(X)，以中心Jacobian近似逆Y预条件，用区间Gauss-Seidel收缩：

```text
(Y * J(X)) * (x-c) ∈ Y * (allowed - F(c))
```

对角含0则跳过，不能将奇异判成无解。近似逆仅作预条件，证明计算用向外舍入区间。另逐约束/坐标使用区间Newton：固定当前坐标为中点、其他坐标保持区间，以整个盒的偏导包围收缩，所以也支持非方系统与厚观测带。

传播与Newton有界交替。`Contraction.box=None`证明没有满足约束的定义点；非空不证明存在解。fixed_point只说明当前机制停止变化，不是最强收缩或全局可行。未达固定点的停止如实标budget_exhausted。

## 搜索和证据

根的唯一性仍需严格Krawczyk：q<1且映像在域内部。Newton/传播不单独生成唯一性证书。若逆传播把正规根缩成点，在原盒内保留小邻域供存在性证明；放宽只降低效率，不丢根。

pave在联合收缩后作整盒判定/SIVIA。内盒全部点满足全部约束；内盒∪未决包围原域全部可行点。全查询共享contractors.max_steps，耗尽后继续区间判定/细分，不丢待处理区域；搜索评估、深度和收缩轮次均有界。
