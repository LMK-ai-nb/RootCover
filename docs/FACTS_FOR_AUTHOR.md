# 0.2 申报可核对事实

参赛者李明坤，GitHub/Mooncakes LMK-ai-nb，个人参赛，无队友，2026年11月，拟选新项目参与季度评选。以下事实供审阅和本人解释，不证明审核已通过。

- 名称：RootCover，多项式根与观测容差可行域的区间求解库。
- 用户：几何计算、标定和定位软件、科学模型开发者；MoonBit库独立执行，无其他数值平台依赖。
- 0.1已有：区间运算/自动Jacobian/Krawczyk根域搜索、明确未决、typed API/JSON/CLI/Worker。
- 0.2已实现：非方观测带约束、整盒可行证据、SIVIA内外包围、分辨率与完成状态分离；标定容差、测距误差工作流和导出。
- 根模式1…6维方形系统；观测带模式1…6变量、1…32约束。两者仅多项式、binary64点系数和有限输入范围。观测输出带不是系数不确定族或统计置信度。
- 三完整场景：圆线交点两个根；非单调标定三分支及加入容差；三个测距带约束两个坐标得到19个可行盒、40个未决盒，达到1/64分辨率。全部是合成模型。
- 另有反应稳态、三维测距镜像解、六元64根和重根边界反例。
- 本轮33项MoonBit（含3项文档）、13项CLI。求根独立核对2800组算术、182系统、513份证据；可行域37系统、1310份内盒证据、4413个有理数网格点。CI41842581871三平台四目标全部成功；Mooncakes0.2.0实际发布200并被独立消费工程下载运行，八个核心文件匹配。证据见RELEASE.md。
- 方法已有成熟研究；不主张世界唯一或方法发明。不以底层区间四则重写作为独立贡献，主要交付是两个完整求解流程及误差观测模型。具体对照见RESEARCH.md。
- 独立实现，无第三方核心源码移植；MIT与标准库许可保留。与TideWeave、TripFrontier无业务核心复用，不冒认其他会话工程归属。
- 尚无真实工业采用/大型生产模型证据，不支持超越函数/复根/任意精度/全局优化。0.2已实现的观测输出带不应被错误写成支持所有类型的不确定参数。
- 最新要求准备AI辅助审阅稿并披露。李明坤复核、运行和解释后按工作人员适用口径处理；官方报名/银行/诚信/群昵称/回执仍由本人确认。
