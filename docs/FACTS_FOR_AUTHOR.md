# 供本人写申报书的事实清单

本文件提供可核对事实，不是正式申报正文。参赛者李明坤，GitHub/Mooncakes LMK-ai-nb，个人参赛，无队友。申报月份为2026年11月，拟选新项目参与季度评选；资格、名额和最终有效提交以官方记录为准。

- 名称：RootCover，多元多项式方程组区间求解引擎。
- 用户：几何计算、标定软件、科学模型开发者；可复用MoonBit库，不要求依附某个已有项目。
- 问题：指定区域可能有多个根；一个初值、一个近似值或很小残差，不能直接说明区域内所有根及唯一性。
- 已实现：合法模型、向外舍入区间、区间自动微分、Krawczyk排除/收缩/严格唯一性、区域划分、精化、显式未决、预算；typed API、JSON、CLI、Worker浏览器。
- 三个场景的用户、输入、操作、输出、验证均在SCENARIOS.md，都是已运行的合成示例。
- 验证：23项MoonBit、7项Node；2800组区间、180模型、447份精确证据重放。远程发布/CI以RELEASE.md的实际记录为准。
- 差异：浮点/区间算术是基础层，本工程的目标是方程根区域求解；不声称与其他项目完全没有交集、不声称算法首创。RESEARCH.md说明必要性、已有能力、调研局限。
- 原创：独立实现，无第三方核心源码移植；MIT与标准库许可均保留。旧工程业务关系在ORIGIN.md。
- 边界：1…6维方形多项式、binary64系数、有限区域；重根/边界根可未决，不做超越函数/复根/全局优化/不确定系数/安全认证。
- 未完成：真实工业模型采用验证、规模与病态系统的系统评测、更高精度后端及更强分割；不要写成已经具备。
