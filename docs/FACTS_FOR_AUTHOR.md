# 当前本地0.3可核对事实

参赛者/维护者李明坤，GitHub/Mooncakes LMK-ai-nb。0.3是RootCover0.2的本地扩展，未推送或发布；旧公开仓库/Mooncakes0.2不含新增能力。不能将本地开发说成线上已交付或审核已通过。

- 新定位：实非线性方程与混合约束的区间求解库，不再仅限低维多项式。
- 13种初等函数、除法/负整数幂、定义域和光滑性状态、区间AD。
- HC4风格前向—反向传播与变量依赖agenda，独立区间Newton及公平有界联合收缩；保守SIVIA内外包围。

- 机构逆解与容差、指数参数估计、log/sqrt混合约束三完整场景；全部合成，不声称真实设备采用。
