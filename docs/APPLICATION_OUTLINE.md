# 一页Markdown本人填写提纲

以下各栏均由参赛者本人用自己的语言填写，不把提示句当成正文提交。

- 参赛者/账号/参赛形式/月份与方向：____
- 项目名称：____
- 项目简介（用户遇到什么问题，输入什么、实际产出什么）：____
- 项目方向与通用性（哪些开发者、为何需要独立求解库）：____
- 完整场景一：使用者____；问题____；输入____；操作____；输出____；验证____。
- 完整场景二：使用者____；问题____；输入____；操作____；输出____；验证____。
- 完整场景三：使用者____；问题____；输入____；操作____；输出____；验证____。
- 拟承诺的核心功能与已完成部分：____
- 与最接近的已有项目相比，需要独立建设的理由及具体区别：____
- 原创/参考/移植关系、来源链接与许可证：____
- 已运行的测试/复现证据及未完成边界：____
- GitHub公开仓库链接：____
- 可选演示与Mooncakes入口：____

写完控制在一页Markdown内；不要承诺未实现能力，不将小残差写成唯一性证明，不把合成数据写成客户落地或实际设备结论。
